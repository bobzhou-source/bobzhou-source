# Robert Zhou

Software, AI models, and computational biology at Colby College (Pulver Science Scholar). Also indexed as **Bob Zhou** and **Qunbo Zhou**.

Site: **[robertzhou.dev](https://robertzhou.dev)**

- [colby-gpu-cluster](https://github.com/bobzhou-source/colby-gpu-cluster): a native macOS menu-bar app that shows which Colby HPC GPUs are free, running, or queued, drawn as an isometric city. One Swift package, no third-party dependencies.
- [director-shell-mcp](https://github.com/bobzhou-source/director-shell-mcp): a small MCP server that lets director-mode agents write files, run Python and shell commands, and supervise background jobs, only when a tool is called.
- [powerbi-pbir-mcp](https://github.com/bobzhou-source/powerbi-pbir-mcp): a standard-library Python MCP server for editing Power BI reports saved in PBIR format, with batch layout changes and validation.
- [mayflower](https://github.com/bobzhou-source/mayflower): a SwiftUI degree-audit app for macOS and iOS covering 100 Colby College programs.
- Writing on [Substack](https://substack.com/@bobzq) and short videos on [The Lab](https://www.tiktok.com/@the.lab67).
